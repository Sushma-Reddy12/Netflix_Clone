#  Netflix Clone – HTML & CSS

A simple and responsive **Netflix Clone** website built using **HTML and CSS**. This project recreates the basic look and feel of the Netflix streaming platform, focusing on the homepage layout, navigation bar, movie sections, banners, and responsive design.

##  Features

*  Netflix-inspired homepage
*  Navigation bar with menu options
*  Search UI
*  Profile/account section
*  Movie and TV show sections
*  Movie posters and banners
*  Watch/Explore buttons
*  Responsive design for different screen sizes
*  Clean and modern Netflix-inspired UI

##  Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsiveness

##  Project Structure

```text
netflix-clone/
│
├── index.html
├── style.css
├── images/
│   └── movie posters and banners
└── README.md
```

##  How to Run

1. Clone the repository

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
